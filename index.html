DAX Formulas & Data Modeling Architecture

Direct inspection of all business logic measures, relationships, and ETL transformations

[Total Sales] Core Financial 
Total Sales = 
SUM ( 'Fact_Orders'[Sales_Amount] )

Computes aggregated top-line retail sales revenue across active filter context.

[Total Profit] Core Financial 
Total Profit = 
SUM ( 'Fact_Orders'[Profit_Amount] )

Calculates net gross profit considering manufacturing cost, shipping, and discount write-downs.

[Profit Margin %] Efficiency Measure 
Profit Margin % = 
DIVIDE ( 
    [Total Profit], 
    [Total Sales], 
    0 
)

Safe division to protect against division by zero; outputs relative bottom-line profitability.

[Sales PY (Prior Year)] Time Intelligence 
Sales PY = 
CALCULATE (
    [Total Sales],
    SAMEPERIODLASTYEAR ( 'Dim_Calendar'[Date] )
)

Shifts calendar filter context by 1 full year to establish comparative benchmark.

[YoY Sales Growth %] Time Intelligence 
YoY Sales Growth % = 
VAR CurrentSales = [Total Sales]
VAR PriorYearSales = [Sales PY]
RETURN
    DIVIDE ( CurrentSales - PriorYearSales, PriorYearSales, 0 )

Dynamic variable evaluation computing year-over-year revenue expansion rate.

[Average Order Value] Order Metrics 
Average Order Value = 
DIVIDE (
    [Total Sales],
    DISTINCTCOUNT ( 'Fact_Orders'[Order_ID] ),
    0
)

Evaluates revenue per unique transaction header for basket size analytics.
